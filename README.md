# JOLIBEN — Public Website

An independent AI and product-development project by Thiemo Gerhardt.

This repository contains **only the public presentation website**, including the explanatory agent simulation, selected project work and the development roadmap. The working JOLIBEN system and its application source remain private and separate.

- **Website:** https://joliben.github.io/joliben-website/
- **Language:** German / English
- **Contact:** [thiemo.gerhardt@icloud.com](mailto:thiemo.gerhardt@icloud.com)
- **Simulation:** The interactive agent experience is explanatory; it does not call live AI models or private services.

The website is implemented as static HTML, CSS and JavaScript, hosted via GitHub Pages.

## Publication

GitHub repository **Settings → Pages → Deploy from a branch → `main` → `/(root)`**.

For updates, make a reviewed commit to this public repository only. No internal project documents, logs, model credentials, runtime data or private source code should be committed here.
